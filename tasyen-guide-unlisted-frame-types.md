# Frame Types Intentionally Not Added

This tracker records native frame types intentionally excluded from MonoFrame
coverage because Tasyen's documentation does not provide enough construction
guidance. Sources are version unspecified.

| Native type | Component | Library status | Evidence |
| --- | --- | --- | --- |
| `CONTROL` | — | Not added | Tasyen's [CONTROL reference](https://github.com/Tasyen/FDF/blob/master/FrameTypes/CONTROL.html) contains only a heading, not construction guidance. |
| `STATUSBAR` | — | Not added | The Hive guide lists `SIMPLESTATUSBAR`, not `STATUSBAR`. Tasyen documents native `STATUSBAR` separately in the [FDF STATUSBAR reference](https://github.com/Tasyen/FDF/blob/master/FrameTypes/STATUSBAR.html). |
